# Quotidien

Tâches et emploi du temps personnels, installables comme une application (PWA).
Les données restent sur l'appareil (localStorage) ; l'application fonctionne hors ligne.

## Installer
- iPhone : ouvrir l'adresse dans Safari, Partager, « Sur l'écran d'accueil ».
- Android / Huawei : menu du navigateur, « Installer l'application ».

## Mettre à jour
Après un changement de `index.html`, incrémenter `VERSION` dans `sw.js`.
